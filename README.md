## How this repo is organized

- Each `Chapter - XX` folder groups files by the order topics were learned.
- File names are numbered (`01_`, `02_`, ...) to reflect the sequence within a chapter.
- Files named `Practice` / `*Practice*.py` contain practice questions and solutions for that chapter's topics.
- Some chapters (07, 10, 11) also include small `.txt` files used as sample data for file-handling exercises.

## Status

This is an ongoing learning log — new chapters and topics will be added as more Python concepts are covered.
